Privacy Policy

RDC Channel Analytics. Last updated October 17, 2026.

What this application is

RDC Channel Analytics is a private tool used by one person, its operator, to read analytics for YouTube channels the operator owns. It is not a public service and has no users other than the operator.

What data it accesses

With the operator's consent through Google sign-in, the application reads YouTube Analytics reports (views, watch time, traffic sources, audience retention and estimated revenue) and basic YouTube channel and video details for the operator's own channels. Access is read-only.

How the data is used and stored

The data is stored on the operator's own computer and in a private backup the operator controls. It is used only to understand how the operator's videos perform. It is not sold, shared with third parties, used for advertising, or combined with data about other people.

Google user data

The application's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from the Google Account's third-party access settings. Removing access stops all further data collection.

Contact

Questions go to the support email shown on the Google sign-in consent screen for this application.
